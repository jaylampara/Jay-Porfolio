WHO I WORKED WITH — CLIENT / PARTNER LOGOS
==========================================

Drop logo image files into this folder and they appear automatically in the
moving logo strip above the reviews section. No code changes are needed.

Supported files
---------------
  .svg  .png  .webp  .avif  .jpg  .jpeg  .gif

How labels work
---------------
* The file name becomes the logo's label (alt text and hover tooltip).
  "03 - Circles Ola.svg"  ->  "Circles Ola"
  "acme_studio.png"       ->  "acme studio"

* To choose the label yourself, add a same-numbered .txt file:
      1.svg   +  1.txt  (contents: Label: Circles Ola)

* Numbered files appear in number order; anything else follows by name.
  Use a number prefix if the order matters.

Logo tips
---------
* SVG is best: it stays crisp at every size and is usually the smallest file.
* Use a transparent background and keep the artwork roughly 3:1 or wider.
* Logos are scaled to fit inside a 164 x 70 box on desktop, 138 x 62 on phones.

Optional
--------
If this strip is empty, the section stays hidden. Delete every logo file to
hide it again.

Files in this folder right now are sample stand-ins. Replace them with real
client logos before publishing.

Note: plain-numbered files (1.svg, 2.png …) carry no name in the file name, so
they show as "Client 01", "Client 02" … Add a label txt or rename the file to
show a real client name.

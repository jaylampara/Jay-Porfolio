# Archive No. 09 — sample works

Each subfolder of THIS folder is a tab in the modal. Inside every tab
folder, freely mix (files ordered by the number in their name):

  PHOTOS      1.png, 2.jpg, 3.webp …
  VIDEOS      1.mp4, 2.mov, 3.webm …  (vertical/horizontal auto-detected)
  LINK FILES  1.txt, 2.txt …  one URL each on the first line, optionally
              " | label" — YouTube/Vimeo, Drive, Dropbox, X/Twitter,
              Streamable, Dailymotion, Loom, TikTok, Instagram, Facebook,
              or any direct photo/video link. Lines starting with # are
              ignored. (Drive files must be shared "Anyone with the link".)

Add / rename / delete folders freely — tabs follow automatically.

This README is ignored by the gallery.

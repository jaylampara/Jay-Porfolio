# Poster & Identity System — graphics design samples

Whatever is in THIS folder shows in the Poster & Identity System modal.
Free mix, no fixed count — files are ordered by the number in their name:

  PHOTOS      1.png, 2.jpg, 3.webp …  (PNG/JPG/JPEG/WEBP/GIF/AVIF)
  VIDEOS      1.mp4, 2.mov, 3.webm …  (vertical/horizontal auto-detected)
  LINK FILES  1.txt, 2.txt …  each holding one URL on its first line,
              optionally " | label" — YouTube/Vimeo, Google Drive,
              Dropbox, X/Twitter, Streamable, Dailymotion, Loom, TikTok,
              Instagram, Facebook, or any direct photo/video link. Lines
              starting with # are ignored.

Google Drive notes: the file must be shared as "Anyone with the link"
(Viewer). Drive videos play in Drive's own player (with its own sound
control) with their real shape detected; Drive photos become normal
photo tiles — add the word "photo" to the label if it ever misreads.

Add subfolders to group designs — each subfolder automatically becomes a
TAB in this modal (number the names to order tabs, e.g. "1 - Posters").
Note: once subfolders exist, files sitting straight in this root are no
longer shown; move them into a subfolder then.

This README is ignored by the gallery (it is not a media file).
